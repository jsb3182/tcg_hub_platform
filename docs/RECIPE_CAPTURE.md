# 뉴런 레시피 이미지 인식

유희왕 뉴런에서 내보낸 세로 10열 이미지를 읽습니다. 브라우저가 JPG·PNG·정지 WebP의 파일 크기(8 MiB)와 해상도(1,200만 픽셀)를 검사한 뒤 카드 칸, 구역, 반복 그림을 찾습니다. 파일과 카드 칸 썸네일은 현재 탭에서만 사용합니다. 제목은 지원되는 기기의 문자 인식 또는 사용자가 지정한 파일명에서 가져옵니다. 둘 다 없으면 직접 입력합니다.

그림 비교에는 두 출처를 사용합니다.

- 설치된 서버의 공개 유희왕 아틀라스는 도감의 실제 카드·일러스트 ID와 연결됩니다. 브라우저는 시트 해시를 키로 숫자 지문만 IndexedDB에 저장합니다. 비공개 카드와 회수한 시트는 새 검색에서 제외합니다.
- 일본어 NEURON 그림은 Konami 카드 데이터베이스 ID(CID)와 그 카드의 공식 일러스트 번호로 비교합니다. YGOResources는 카드 인식용 지문 생성에 한 언어의 저장소를 복제하고 필요할 때 개별 그림을 읽는 방식을 안내합니다. 앱은 15,030개 지문(886,778바이트)과 매니페스트가 제공한 경로를 배포합니다. 개별 이미지는 검토·다시 열기·PNG 출력에 필요할 때 해당 CDN에서 읽습니다. 그림의 원저작권은 Konami에 있습니다. [YGOResources 자료 이용 안내](https://github.com/yugioh-artworks/artworks-index#readme)

후보는 설치된 도감의 공개 카드로 제한합니다. 같은 그림이 여러 팩에 실렸다면 비교만으로 정확한 팩과 희귀도를 식별할 수 없어 대표 공개 인쇄본을 제시합니다. 검수에서 인쇄본과 구역을 바꿀 수 있습니다. 저장할 때 서버는 선택한 실제 판이 해당 CID의 매니페스트에 있는지 검증합니다. 같은 카드의 다른 판은 별도 수량과 이미지로 저장되며 덱 공유와 덱 코드에서도 유지됩니다. 외부 그림을 불러오려면 CDN 연결이 필요합니다.

부분 캡처, 좁은 갤러리 썸네일, 수평으로 잘린 첫 줄, 강한 빛 반사, 레이아웃이 다른 캡처는 검수 대상으로 남을 수 있습니다. 특히 메인 뒤에 구역이 하나만 보이면 남은 구역의 제목과 카드 위치를 확인하세요. 그림의 색·배치 유사도와 다음 후보와의 점수 차이를 기준으로 표시한 신뢰 수준은 정답 확률을 뜻하지 않습니다.

## 지문 재현

이번 지문은 [일본어 NEURON 사진 리비전](https://github.com/yugioh-artworks/artworks-jp-n/tree/0ed24303a557ec1f78dca645544aaddc43974508)과 [경로 매니페스트 리비전](https://github.com/yugioh-artworks/artworks-index/tree/433fe3d2223d3453b7732b5bad016196fb7b092f)에서 만들었습니다. 원본 매니페스트 SHA-256은 `86933497cb03bcf6dd4826549f586a4aa6d9863b8296e0b4775095c867b78f22`, 지문 파일은 `e26b3c18c49dfe2741ca1fc7788dac8f73f7f1858d907347ce07f17beda67b86`입니다.

PC에서 기존 단일 언어 복제본을 증분 갱신합니다. 사용자의 휴대폰에서 원본 저장소를 받지 않습니다. 필요한 로컬 입력이 준비된 상태에서 다음 명령을 실행합니다.

```sh
python frontend/tools/build-recipe-fingerprints.py manifest.json artworks-jp-n frontend/src/recipeCaptureNeuron.bin
python frontend/tools/build-recipe-artwork-rows.py manifest.json new-artwork-rows.sql
```

두 번째 명령은 명시적으로 제공된 일본어 그림 경로만 SQL 값으로 출력합니다. 후속 배포는 기존 덱이 참조한 CID·판을 유지하는 새 마이그레이션으로 추가합니다. 배포한 V29의 체크섬은 고정합니다.
