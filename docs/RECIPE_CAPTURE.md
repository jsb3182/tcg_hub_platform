# 덱 레시피 캡처 가져오기

**내 덱 → 새 덱 추가 → 전체 레시피 캡처**에서 JPG, PNG 또는 정지 WebP 파일을 선택합니다. 유희왕 뉴런에서 저장한 전체 레시피는 카드 위치와 구역을 자동으로 찾습니다. 여섯 종목 모두 직사각형 격자로 배열된 레시피를 가져올 수 있습니다.

## 격자로 배열된 레시피

1. 유희왕은 **캡처 형식 → 격자 지정**을 고릅니다. 다른 종목은 파일을 고르면 격자 미리보기가 열립니다.
2. **가로 칸**과 **세로 칸**을 입력하고 카드 영역의 네 가장자리를 맞춥니다. 제목이나 바깥 여백이 있는 캡처는 미리보기의 선이 각 카드 테두리에 맞도록 조정합니다. 한 번에 최대 120칸을 비교할 수 있습니다.
3. **서버의 카드와 대조**를 누릅니다. 브라우저는 캡처를 최대 1 MiB의 JPEG로 줄여 로그인한 허브에 보냅니다. 서버는 지정한 영역을 나누고, 해당 종목에서 그림 지문을 갖춘 공개 인쇄본 중 칸마다 최대 세 후보를 찾습니다.
4. 캡처와 후보 그림을 비교해 카드·구역·매수를 확인합니다. 빈 칸은 **이 항목 제외**, 후보에 없는 카드는 **도감에서 직접 찾기**로 처리합니다. 검수를 마치면 **확인한 카드를 덱에 추가**를 누릅니다.

## 유희왕 뉴런 자동 인식

유희왕 뉴런에서 내보낸 세로 10열 이미지를 읽습니다. 브라우저가 JPG·PNG·정지 WebP의 파일 크기(8 MiB)와 해상도(1,200만 픽셀)를 검사한 뒤 카드 칸, 구역, 반복 그림을 찾습니다. 파일과 카드 칸 썸네일은 현재 탭에서만 사용합니다. 제목은 지원되는 기기의 문자 인식 또는 사용자가 지정한 파일명에서 가져옵니다. 둘 다 없으면 직접 입력합니다.

그림 비교에는 두 출처를 사용합니다.

- 설치된 서버의 공개 유희왕 아틀라스는 도감의 실제 카드·일러스트 ID와 연결됩니다. 브라우저는 시트 해시를 키로 숫자 지문만 IndexedDB에 저장합니다. 비공개 카드와 회수한 시트는 새 검색에서 제외합니다.
- 일본어 뉴런 그림은 Konami 카드 데이터베이스 ID(CID)와 일러스트 번호로 구별합니다. 브라우저는 앱에 포함된 15,030개 지문(886,778바이트)을 비교합니다. 검수·덱 상세·PNG 출력에 쓰는 카드 그림은 허브의 미디어 저장소에서 읽습니다. 그림의 원저작권은 Konami에 있습니다. [지문 원본 자료](https://github.com/yugioh-artworks/artworks-index#readme)

후보는 설치된 도감의 공개 카드로 제한합니다. 같은 그림이 여러 팩에 실렸다면 대표 공개 인쇄본을 제시합니다. 검수에서 인쇄본과 구역을 바꿀 수 있습니다. 저장할 때 서버는 선택한 일러스트 번호를 해당 CID의 매니페스트와 대조합니다. 같은 카드의 다른 판은 별도 수량으로 저장되며 덱 공유와 덱 코드에서도 유지됩니다. 도감에 일러스트 번호가 있어도 해당 판의 그림이 아직 로컬에 준비되지 않았을 수 있습니다.

부분 캡처, 좁은 갤러리 썸네일, 수평으로 잘린 첫 줄, 강한 빛 반사, 레이아웃이 다른 캡처는 검수 대상으로 남을 수 있습니다. 특히 메인 뒤에 구역이 하나만 보이면 남은 구역의 제목과 카드 위치를 확인하세요. 그림의 색·배치 유사도와 다음 후보와의 점수 차이를 기준으로 표시한 신뢰 수준은 정답 확률을 뜻하지 않습니다.

PC에서 기존 단일 언어 복제본을 증분 갱신합니다. 사용자의 휴대폰에서 원본 저장소를 받지 않습니다. 필요한 로컬 입력이 준비된 상태에서 다음 명령을 실행합니다.

```sh
python frontend/tools/build-recipe-fingerprints.py manifest.json artworks-jp-n frontend/src/recipeCaptureNeuron.bin
python frontend/tools/build-recipe-artwork-rows.py manifest.json new-artwork-rows.sql
```

두 번째 명령은 명시적으로 제공된 일본어 그림 경로만 SQL 값으로 출력합니다. 후속 배포는 기존 덱이 참조한 CID·판을 유지하는 새 마이그레이션으로 추가합니다. 배포한 V29의 체크섬은 고정합니다.
