## 비회원 화면

같은 날 00:06 KST, USB로 A90에 연결한 PC Chrome에서 360px와 1280px 화면을 확인했다.

- 한국어 도감 첫 페이지 24장 모두에 한국어 이름과 한국어 그림이 표시됐다.
- 발매 일정 첫 화면의 네 분류와 로그인 링크가 두 화면 폭에서 모두 보였다. ‘팩 발매 일정’에서 ‘덱 빌드 팩 글로리어스 빅터즈’를 열면 45장이 두 페이지에 30장과 15장으로 나뉘었다. 모두 접혀 있었고, 카드 선택 전 개별 상세 요청은 0회였다.
- 니벨아레나 ‘키사키(수영복)’(`BT09-001`)에서 한국어 효과와 한국어판 그림을 확인했다. 저장된 WebP는 225×315px였고, 화면에서는 각각 약 108×151px와 172×241px로 표시됐다.
- 바이스 슈발츠의 한국어 카드명 390건을 A90에 반영한 뒤 같은 자료로 다시 검사했다. 390건 모두 일치했고 추가 반영은 0건이었다. [인쇄 번호별 근거와 반영 도구](../../tools/weiss-korean-supplement/)

00:07 KST에 A90의 앱 아이콘을 눌러 ‘카드 도감’을 열었다. 앱 버전은 2.0.19(코드 29)였고, ‘문 가드너’, ‘패러렐 텔레포트’, ‘엑소시스터 리타니아’가 표시됐다. 로그인 없이 요청한 관리자 API는 HTTP 401을 반환했다.

같은 기기의 바이스 슈발츠 공개 도감에서 고유 인쇄본 19,321장을 전수 조회했다. 한국어 이름이 표시되는 인쇄본은 13,377장, 한국어 효과가 표시되는 인쇄본은 16,325장이었다. 한국어 이름에는 참고 번역과 기계번역이 포함된다. 영어 효과가 있는 18,689장 중 2,364장은 한국어 효과가 대기 중이며, 632장은 출처에 영어 효과가 없었다.
